Source invoice PDFs stay in your browser.

This validation version is designed so the PDF files you select are read by JavaScript running in your browser. The source invoice PDFs are not intentionally uploaded to an application server for analysis.

Plain-English version: when you choose two invoice PDFs, the comparison runs on your device. Refreshing or closing the page clears the current comparison state.

What is processed locally

The browser reads text from the PDFs, attempts to identify invoice dates, totals, line items and recurring fees, and compares the two normalized invoice structures. The resulting comparison is kept in page memory for the current session.

What may still reach infrastructure providers

Like most websites, ordinary web requests can expose technical metadata such as IP address, browser type, requested URL and timestamps to the hosting provider. This site is hosted on Cloudflare Pages. PDF.js is loaded from jsDelivr, so the browser also makes a normal request to that CDN for the software library. The invoice file itself is not intentionally sent with those requests.

Analytics

This validation version does not use third-party analytics that read invoice contents. Product events may be added later, but invoice text and line-item values should not be included in analytics payloads.

Important limitation

Browser-side processing reduces server-side document exposure, but it does not make the website a regulated document vault. Do not use the checker for material that you are not authorized to process.
